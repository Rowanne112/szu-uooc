# 0.1.8 稳定性验收

脚本版本为 `0.10.0-local.24`。本版通过模拟课程、本机 HTTP 服务及独立测试浏览器验证，没有访问真实课程或付费解题接口。

## 根因与修复

- 目录请求和原生导航没有操作截止时间：增加 15 秒超时，最多三次请求，补试等待 1、2 秒。
- 页面状态缺失无限等待或坏 JSON 导致退出：增加心跳检查、有限页面恢复及安全暂停。
- 旧任务排队请求、账本写入期间取消仍发请求：核对运行编号、原文档状态节点，并在发送前再次核对；确认未发送的请求计零费用。
- 旧标签覆盖接管后的断点：仅持课程锁的标签可写共享断点，停止先保存再释放锁。
- 一次写盘失败永久阻断后续保存：修复持久化队列的失败恢复。
- 停止入口损坏时假暂停：确认实际停止；无法确认则撤销本控制器注入并刷新终止旧文档。
- 暂停断点保存失败后刷新重启：同时核对实际停止与暂停断点，不可确认时终止旧文档。

## 恢复与人工处理

视频连续 30 秒没有进展时先复用线路切换，其后最多一次媒体重载、一次原生资源重开。恢复次数跨刷新保留，播放位置约每五秒保存一次，完成状态仍以平台为准。

网站明确验证失败最多重开三次，等待 5、10、20 秒；原生控件连续点击失败最多尝试三次，补试等待 5、10 秒。额外挑战由人工处理。未知费用、交卷未确认、断点损坏和持续性故障安全暂停，不删除历史费用或重复交卷。

最近 100 条脱敏记录保存于用户数据目录的 `recovery-log.json`；页面恢复记录位于 `evidence/course-课程ID/recovery.jsonl`，同样限 100 条。

## 验证结果

- 完整源码工作区回归：153 通过，0 失败，0 跳过。
- 最终暂停持久化修复后，控制器恢复与实际 IPC 回归：24 通过，0 失败，0 跳过。
- 题库导入断言与 JavaScript 语法检查通过。
- ZIP 完整性、31 项文件 SHA-256，以及六个修改运行源码与安装包逐字节一致性检查通过。
- 故障注入包括断网、永不返回、503、401、响应断流、坏状态、导航超时、视频停滞、旧响应迟到、并行标签、停止入口消失与存储写入失败。

这些测试在维护者的源码工作区执行；本仓库及轻量安装包保持安装目录结构。未进行真实课程长时挂机、Windows 或 Intel Mac 实机验收。

## 更新后验收

停止旧程序，完整解压新版到新文件夹；开始一门课，短暂断网后恢复，再检查刷新续跑与手动暂停后刷新不会重启。进度与完成情况请在课程平台核对。
