验收对象：v0.1.10 的稳定恢复、离线浏览器切换与旧控制台识别代码。v0.1.11 沿用同一运行代码，补充本次实机和安装包验收记录。

## 实际操作结果

- 在 macOS Apple 芯片电脑上控制现有 Chrome 操作，使用真实课程网站；没有更改代理或网络路由。校园网认证和课程账号登录由使用者完成。
- 原 Edge 不可连接时，先到网站核对上次测验状态，再按界面人工确认，成功改选 Chrome；控制台显示已连接，原课程列表保留。
- 实际视频播放、控制台暂停、暂停后刷新课程页面、继续播放均通过。刷新后没有自行解除暂停，继续后保留播放位置，网站确认视频完成。
- 现有解题服务能返回模型列表，但不提供可核实报价。程序阻止付费检测和正式解题，检测调用计数为 0；没有用猜测价格绕过预算保护。
- 使用者明确选择免费模式并接受缺题随机作答后，在界面保存该模式。脚本从现有断点继续，自动提交章节测验，网站显示结果页和完成标记。
- 脚本识别提交完成，清除待核对交卷状态，已完成任务数递增，并在目录复查后自动打开下一节视频；真实播放器显示正在播放。

原始截图和含课程标识的运行状态留在验收电脑，不随公开仓库和安装包分发。公开记录不含账号、Key、控制台访问令牌或个人成绩。

## 更新与复验

先在旧控制台点「设置 → 退出程序」，完整解压新版安装包再启动；原有设置和课程记录保存在用户目录。不得同时运行两个安装目录。

可复验路径：选择并连接 Chrome → 读取课程 → 保存免费答题方式或验证可用的 AI 服务 → 继续课程 → 暂停 → 刷新课程页 → 继续 → 核对网站完成标记和下一节播放。
