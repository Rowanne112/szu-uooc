深易刷新手图文使用教程

适用 Windows 10／11 x64 和 Mac（Intel／Apple 芯片）。先准备 Google Chrome 和 UOOC 账号；只有使用 AI 解题时才需要 API Key。

截图以 Windows 为例，Mac 按文中标注操作，其余步骤相同。部分旧版截图显示 szu-uooc，与深易刷是同一程序。

1 下载程序

打开 深易刷下载页，点 ShenYiShua.zip。Windows、Mac 都下载同一个 ZIP。

2 解压并启动

Windows：右键 ZIP → 全部解压，打开文件夹，双击 启动-Windows.cmd。
Mac：双击 ZIP 解压，打开文件夹，双击 启动-Mac.command。
Mac 若被系统拦截：打开 系统设置 → 隐私与安全性，在“安全性”处点 仍要打开，再确认打开。

3 等待组件准备

保持联网，等待自动下载并打开控制台。已有组件会直接跳过；若提示失败，检查网络后重试。

4 打开课程网站

在控制台点 打开 UOOC。

5 登录账号

输入你自己的课程账号和密码，按网站提示手动完成验证，再点 登录。

6 返回控制台

登录成功后，切回深易刷，点 已登录，下一步。

7 打开调试页

点 复制调试页地址，在 Chrome 顶部地址栏粘贴，按回车。

8 勾选远程调试

勾选 Allow remote debugging，勾选后应如图。此权限可控制浏览器，只连接你信任的本机程序。

9 连接 Chrome

切回深易刷，点 已开启，连接 Chrome。

10 允许本次连接

在 Chrome 弹窗点 允许。程序会自动读取课程，等待课程列表出现。

11 选择答题方式

不填 Key：点 先不填，免费开始，跳到第 13 步。免费模式优先题库，缺题随机作答并自动提交，可能答错；缺答案的填空题需人工处理。
想用 AI：点 设置解题服务，按下一步填写。以后也可从 设置 → 解题服务切换。

12 可选：设置 AI 解题

答题方式选 AI 解题，粘贴服务商提供的 API Key，展开 高级设置。免费模式跳过这一步。

按服务商信息核对接口、模型、实际价格和预算。点 测试连接，成功后点 保存设置。图中价格仅是程序默认值。

13 开始一门课程

找到要学习的课程，点旁边的 开始，等待课程页面打开。一次只运行一门；完成后再手动开始下一门。

14 结束使用

临时停下可点 暂停，回来点 继续；换课先 停止。完全结束时点 设置 → 退出程序。只关网页，程序仍会运行。

课程没有读出来时

先点 刷新课程。仍没有课程，点 粘贴网址。

在 UOOC 打开课程并进入学习页，复制地址栏完整网址（含 # 后面的内容）。粘贴到输入框，一行一门，点 加入全部课程。

可选 每天自动签到

在 Chrome 安装 Tampermonkey 篡改猴。回深易刷，点 设置 → 每日签到。

选择已登录 UOOC 的 Chrome 资料，点 测试打开，核对账号，确认打开的是你自己的账号。

点 安装／更新签到兼容脚本，在篡改猴页面点 安装。停用旧版同名自动学习脚本，回控制台勾选 已更新此脚本。

勾选 开启每日自动签到 和 登录电脑后自动启动程序；执行方式保持 启动立即签到。

勾选需要签到的课程，点 保存签到设置。之后电脑开机登录并联网，程序会按设置打开课程页面；签到结果到 UOOC 核对。

遇到这些提示时

去验证：程序会自动重试；仍卡住时，点“去验证”手动处理，通过后自动继续。
连接失败：检查 Chrome 调试开关，再回控制台重新连接并允许。
以后使用：再次双击同一个启动文件，按页面提示连接 Chrome，再选课开始。
