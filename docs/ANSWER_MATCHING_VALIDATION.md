# 题库匹配修复验收

2026-10-23，v0.1.23 / 脚本0.10.0-local.36。

本轮修复两项：代码字符串内连续空白在题库匹配、答案校验及原生回填中被错误折叠；导入多行选项时续行被丢弃。保留现有精确匹配、缓存优先级及AI缓存策略。最终提交时换题复核不在本轮范围。

匹配只折叠引号外空白，支持转义引号、续行和C字符前缀，并避免把英文撇号当成字符串起点。页面提取保留原始语义空白与段落分隔。含引号题使用新版缓存键，避免旧有损键继续碰撞；旧记录不删除，普通题旧缓存保持复用。

导入器保存完整选项续行，在明确的解析、评语、作答信息行边界停止拼接。重复选项检查与JS采用相同的空白语义，完整选项外围空白不妨碍直接以文字标注答案。DOCX段落与换行、PDF提取适配器均有回归；PDF解析引擎未实测。
