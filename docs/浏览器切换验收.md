# 浏览器改选修复验收（2026-10-19）

## 原因与修改

控制台的 `/api/browser-select` 在保存 Chrome / Edge 选择前，只要保留了课程网址，就会连接当前浏览器检查未确认交卷。新选中的 Edge 尚未连接、也尚未完成课程核对时，这一步仍会执行，导致改选 Chrome 反而报“Edge 连接未完成”。

复现命令：

```sh
node --test --test-name-pattern='unconnected browser selection' szu-uooc/tests/browser-selection.test.mjs
```

修复前输出：`400 !== 200`，响应为 `{"error":"Edge 连接未完成。检查调试开关，允许连接后重试。"}`。

修改限于 `student/console-server.mjs` 的切换检查条件：当前选择仍需重新读取课程，且当前没有连接时，可以直接改选。已连接的浏览器，以及已经完成课程核对的浏览器，继续检查交卷结果。运行中的课程、正在停止的进程、签到运行和同账号确认继续受原校验保护。改选后依然要求连接、重新读取课程，才能开始学习。

## 验证

新增三个接口回归，覆盖连接失败后 Edge → Chrome、重启保留、未连接时 Chrome → Edge、重新读取课程前禁止开始、已连接且交卷未确认的拦截，以及已启用浏览器断开后不能绕过交卷检查。

```sh
node --test szu-uooc/tests/browser-selection.test.mjs szu-uooc/tests/browser-session.test.mjs szu-uooc/tests/checkin.test.mjs
node --test szu-uooc/tests/browser-selection.test.mjs szu-uooc/tests/console-ui.test.mjs szu-uooc/tests/user-guidance-ui.test.mjs
```

第一组 22/22 通过；补充连接失败及禁止提前开始的断言后，第二组 9/9 通过（两组含重复的浏览器选择测试）。界面测试使用独立 Chromium、模拟课程网站与真实控制器，验证课程导入、暂停/继续/停止、顺序学习、原浏览器复用、手机布局和无 JavaScript 错误。

## 用户验收

退出旧控制台，完整解压新包后启动。点击「更换浏览器」，选择 Chrome，勾选同账号确认并保存；尚未启用的 Edge 无需连接即可切回。接着按 Chrome 的提示连接并读取课程。已有课程与费用记录应保留。

未检查用户现场的浏览器授权、真实课程或 Windows 实机。若原浏览器已用于学习且交卷结果不明，仍会要求先连接原浏览器核对，避免重复交卷。
