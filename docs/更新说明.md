# 发给同学的更新说明

深易刷 v0.1.18 已修复网站验证失败后，自动重试却误报“验证弹窗已关闭”并暂停的问题。

[点击下载最新版](https://github.com/zcx28/szu-uooc/releases/latest/download/ShenYiShua.zip)

原因是旧弹窗还在关闭，程序就立即打开了同一个弹窗；旧的关闭动作随后把它隐藏了。新版会等旧弹窗确实关闭，再重新核对题目并打开验证。

1. 在旧程序点「设置 → 退出程序」。只关网页不会退出后台。
2. 下载新版，完整解压到新文件夹，双击对应系统的启动文件。
3. 连接原来使用的 Chrome 或 Edge，在暂停的课程点「继续」或「开始」。个人设置、进度和费用记录保留。
4. 确认测验完成后能进入下一节；诊断包中的脚本版本应为 `0.10.0-local.29`。

模拟课程回归已通过；原 Windows 电脑的实际续跑仍需确认。网站若要求人工完成验证，按页面提示接管。需要反馈时可使用「设置 → 导出诊断包」，不要发送 API Key。
