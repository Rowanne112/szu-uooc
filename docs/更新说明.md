# 发给同学的更新说明

深易刷新版已更新，请从原来的 GitHub 地址下载：

[点击下载最新版](https://github.com/zcx28/szu-uooc/releases/latest/download/ShenYiShua.zip)

怎么更新：

1. 先在旧程序点「设置 → 退出程序」。
2. 下载新版，完整解压到新文件夹，双击对应电脑系统的启动文件。
3. 首页选择你平时用的 Chrome 或 Edge，按提示连接、读取课程。
4. 用 AI 解题的同学，到「设置 → 解题服务」确认网址和 Key，点「检测并保存」，成功后继续学习。

0.1.7 修复 Mac 双击启动没有沿用系统代理、官方和备用下载地址都超时的问题。首次下载、组件安装和开机启动后的补装都会沿用已有系统 HTTPS 代理。已遇到此问题的同学，请下载最新版后完整解压到新文件夹，再双击启动文件；原来的设置、进度和费用记录会保留。

检测可能产生少量费用，每次上限 $0.02。如果提示价格无法核实，先不要反复重试，截图反馈即可。不要把 API Key 发给别人。
