# 发给同学的更新说明

深易刷 v0.1.15 已更新火山方舟 API 兼容。

[点击下载最新版](https://github.com/zcx28/szu-uooc/releases/latest/download/ShenYiShua.zip)

1. 在旧程序点「设置 → 退出程序」。
2. 下载新版，完整解压到新文件夹，双击对应系统的启动文件。
3. 到解题服务设置，API 网址填写 `https://ark.cn-beijing.volces.com/api/v3`，确认 Key，点击「检测并保存」。模型应已在方舟控制台开通。
4. 检测显示文字/图片模型验证通过后，继续原来的课程。原设置、进度和费用记录保留。

本次修复模型检测、方舟请求参数和欠费/用量上限等错误提示。每次检测仍可能产生少量费用，上限 $0.02；人民币按报价上限保守折算，实际以服务商账单为准。自定义接入点或其他未知报价仍会拦截。

若仍失败，提供报错或「设置 → 导出诊断包」得到的脱敏 ZIP，不要发送 API Key。尚未用同学的真实账号验证本次修复。
