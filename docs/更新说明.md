# 发给同学的更新说明

深易刷 v0.1.17 已修复“找不到唯一的原生选项ID”导致课程暂停的问题。

[点击下载最新版](https://github.com/zcx28/szu-uooc/releases/latest/download/ShenYiShua.zip)

旧程序会把选项文字转换两次，两次处理换行的方法不同。同一个选项就可能被当成不同文字，程序为了避免选错而暂停。新版直接读取网站选项控件自己的编号，再核对保存的答案。

1. 在旧程序点「设置 → 退出程序」。只关网页不会退出后台。
2. 下载新版，完整解压到新文件夹，双击对应系统的启动文件。
3. 连接原来使用的 Chrome 或 Edge，在暂停的课程点「继续」或「开始」。个人设置、进度和费用记录保留。
4. 确认不再出现原生选项编号报错，并能继续当前测验和后续任务。诊断包中的脚本版本应为 `0.10.0-local.28`。

自动测试已通过；原 Windows 电脑与原题实际续跑仍需确认。需要反馈时可使用「设置 → 导出诊断包」，不要发送 API Key。
