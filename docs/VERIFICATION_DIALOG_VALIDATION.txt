原因与证据
网站的 cancelCommitTask 调用 layer.closeAll，commitTask 使用同一个 #commitConfirmDialog 作为弹窗内容。旧程序取消后同步重开，没有等待旧弹窗关闭结束。Layer 的关闭动画结束后会恢复并隐藏原内容，导致刚重开的控件消失。

https://assets.uooconline.com/index/js/paper/student_do_paper-57e6f067a5.js?v=1.0.0.9899
SHA-256：5645af1c743811eb6f711be0cc0302772c2d5a18c5c123c07f51b74544e1aa98
Layer 公开源码的 layer.close 在退出动画开启时延迟 200 毫秒清理对象内容：
https://github.com/layui/layer/blob/master/src/layer.js

复现与修复
模拟网站复用同一弹窗、取消后延迟 200 毫秒关闭：修复前两次复现“验证弹窗已关闭”，实际状态 paused，而预期 complete。立即关闭的对照场景通过。修复后原场景通过，测验只提交一次，后续视频自动完成。

程序现在等待原生弹窗确实关闭，最多等待 5 秒，再重新读取并校验当前课程、任务和完整题目后重开。复用本次答案；关闭期间暂停/停止会撤销重开；关闭超时安全暂停；不改变验证结果、不增加付费请求、不清空进度或费用记录。

源码复现命令（在本地源码项目目录执行）：
node --test --test-name-pattern='verification retry waits for delayed native close' tests/controller-verification.test.mjs
