深易刷

把 ZIP 整个解压，双击「启动-Windows.cmd」或「启动-Mac.command」。
首次启动自动下载组件。按页面的新手指引连接 Chrome，读取全部课程。不会填 API 时可点「先不填，免费开始」，也可设置 AI 解题服务。
免费模式优先题库和缓存；缺题的选择、判断题随机作答并自动提交，可能答错，不保证通过。缺答案的填空等题型请手动完成测验后继续。免费模式不调用解题服务，随机答案不保存到题库。设置中可以切换答题方式。
调试连接：点「复制调试页地址」，粘贴到 Chrome 地址栏并回车，开启该页的 Allow remote debugging，再回控制台连接并在 Chrome 弹窗点「允许」。
点一门课旁的「开始」，程序自动继续整门课的视频与章节测验，一次只运行一门。
暂停后可「继续」本课，或「停止」后换课；完成后手动开始下一门。
学习和原生智能验证使用原来已登录的 Chrome，不启动新的浏览器或新资料。
程序自动点原生验证复选框；若出现额外挑战，点「去验证」在课程窗口接管。
网站提示验证失败时自动等待重试，间隔从 5 秒逐步延长至 30 秒，复用已填答案，不重复请求解题。人工验证通过后保持窗口，程序自动继续提交和后续任务，无需再点「继续」。主动暂停或停止会取消待重试操作。

备用导入：点「粘贴网址」。打开课程 → 进入学习 → 复制完整网址，每行一个。
视频页网址也可以：程序读取整门课目录，继续后续视频和测验，完成情况以网站目录为准。

每天签到：设置 → 每日签到，选择课程和已登录的 Chrome 资料，核对账号，按提示更新兼容脚本。
开启自动签到和「登录电脑后自动启动程序」。默认启动立即打开全部所选课程，同一天不重复。
签到无需解题 Key，也无需每天授权浏览器调试。「今日已打开」仅记录打开命令，签到结果在网站核对。

Key、价格和每门课预算：设置 → 解题服务。每门课费用在课程「更多操作」里查看。
关闭网页后程序继续运行；设置 → 退出程序，会停止学习和签到。
请保留程序文件夹；移动后重新保存自启动设置。
