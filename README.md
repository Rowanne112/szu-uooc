## 老用户怎么更新

1. 在旧控制台点「设置 → 退出程序」。
2. 下载上面的 `ShenYiShua.zip`，完整解压到一个新文件夹，不要直接在压缩包里启动。
3. Windows 双击「启动-Windows.cmd」；Mac 双击「启动-Mac.command」。首次准备组件时保持联网。
4. 原来的个人设置、课程列表和费用记录会保留。首页可点「更换浏览器」，选择平时登录课程的 Chrome 或 Edge，按提示连接并读取课程。
5. 使用 AI 解题的同学，再到「设置 → 解题服务」，确认网址和 Key，点「检测并保存」，检测通过后继续课程。

**不用卸载浏览器，不要删除原来的设置或费用账本。** 更新时不要同时运行新旧两个程序。若切换浏览器时提示上次交卷未确认，请先按提示核对。

- **模型不用自己查、自己填了。** 只填 API 网址和 Key，程序自动筛选并推荐模型；需要时再展开选择一个主要模型。默认仍为原中转站，适配 OpenAI、DeepSeek 官方及部分兼容服务。

检测只证明调用与答案格式可用，不代表课程答题准确率。**服务报价无法核实时，会阻止付费调用**，不要反复重试或自行删除费用记录；截图反馈时不要包含 Key。不保证任意 API 网址都能使用。

## 第一次使用

1. 下载并完整解压安装包，双击对应系统的启动文件，保持联网。
2. 选择已登录 UOOC 的 Chrome 或 Edge，按首页提示开启远程调试，允许本次连接，再读取课程。
3. 点「先不填，免费开始」，或在设置里配置 AI 解题服务。
4. 选择一门课开始。一次只运行一门；网站要求额外验证时按提示手动完成。

免费模式优先题库和缓存，缺题的单选、多选、判断题随机作答并提交，可能答错、不保证通过；缺答案的图片题、填空等题型需人工完成后继续。免费模式不调用付费解题 API。
