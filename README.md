# 深易刷

Windows／Mac 新手版。仓库名称为 `szu-uooc`，旧版界面也会显示这个名称。

## 下载与启动

1. 打开 [最新下载](https://github.com/zcx28/szu-uooc/releases/latest)，下载 `ShenYiShua.zip`（Windows、Mac 共用）。
2. Windows：右键 ZIP →“全部解压”；Mac：双击 ZIP 解压。打开解压后的文件夹。
3. Windows 双击 `启动-Windows.cmd`；Mac 双击 `启动-Mac.command`。保持联网，等待自动下载组件并打开控制台。
4. 按控制台提示登录 UOOC，在 Chrome 开启远程调试并允许本次连接。
5. 读取课程，点“先不填，免费开始”；也可配置 AI 解题服务，再点一门课旁的“开始”。

[查看完整图文教程（飞书）](https://zcntbtjr078i.feishu.cn/wiki/NiWpwxblTiRz3EkASJbcPbmZnQe)。一次只运行一门课；验证码等额外验证按页面提示手动处理。

使用解题服务前请核对服务商的接口、模型、价格与预算。Key 只保存在本机，不要上传到仓库。

## 0.1.3 更新

不填 API Key 也能开始学习。免费模式优先题库和缓存，缺题的单选、多选、判断题随机作答并自动提交，可能答错，不保证通过；缺答案的填空等题型需人工完成测验后继续。随机结果不写入答案缓存。

在“设置 → 解题服务”中可切换答题方式；已有 Key、预算和费用记录保留。

## 0.1.2 更新

- 修复一次网站验证失败就暂停整门课的问题，失败后按 5、10、20、30 秒自动重试，后续间隔保持 30 秒。
- 重用已填答案，不重复请求解题；人工通过后自动继续，主动暂停或停止会取消重试。
- 更新时先在旧控制台点“设置 → 退出程序”，再完整解压新版并启动。个人设置与费用记录保存在用户目录。

## 环境

- Windows 10/11 x64 或 Mac（Intel／Apple 芯片），使用 Google Chrome。
- 首次启动自动下载 Node.js 与浏览器连接组件，后续启动复用。
- 完整图文教程统一在飞书维护，Windows 和 Mac 均可参考。
- 个人配置位于本机用户目录，不包含在发布包中。
